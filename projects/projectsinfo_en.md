# Projects

## 1. "Tameo" - Computer Vision (In Progress)
**Technologies:** Python, PyTorch, YOLO, ZED, DWA, supervised learning, detection/segmentation

Development of the computer vision system for an IA-class boat as part of the Monaco Energy Boat Challenge 2026. Vision pipeline for detection and movement decision; fine-tuning on specialized datasets, data augmentation and model comparison, with improvement of mAP, F1, precision/recall metrics from approximately 80% to 90%.

## 2. Slow - Desktop Application for Traffic Video Analysis
**Technologies:** Python, Tkinter, OpenCV, MySQL, PyMySQL, Matplotlib, PIL/Pillow, Object-Oriented Programming

- **Computer Vision and Vehicle Tracking:** Design of a desktop application to analyze traffic videos, track moving vehicles, and estimate their speed from an OpenCV-based video processing pipeline.
- **Interface, Data and Reporting:** Development of a graphical interface with authentication, user management, lanes, vehicles, and video history, with MySQL storage and detection speed visualization via Matplotlib.

**Repository:** https://github.com/JavierTarazona06/slow

## 3. Skin Segmentation by Statistical Learning - Computer Vision
**Technologies:** Python, OpenCV, NumPy, scikit-learn, Matplotlib, K-Means, Gaussian Naive Bayes, QDA, RGB/HSV/YCrCb

- **Image Processing and Feature Extraction:** Development of a pixel-by-pixel segmentation pipeline to analyze facial images using RGB, HSV, YCrCb color spaces and Cb-Cr descriptors enriched by luminance gradient.
- **Supervised and Unsupervised Learning:** Comparison of supervised Bayesian classifiers (Gaussian Naive Bayes and QDA) with an unsupervised K-Means approach to extract skin masks and visualize results on test images.

**Repository:** https://github.com/JavierTarazona06/Vision_LocalFeatures_BayesianClassification_KMeans/blob/main/docs/rappport/rap.pdf

## 4. ORIUN - Web Platform for International Mobility Application Management
**Technologies:** Python, Django REST Framework, PostgreSQL, Next.js, React, TailwindCSS, Docker, Vercel, Google Cloud APIs, SCRUM

- **Full-Stack Development:** Design of a centralized web platform enabling students to consult calls for applications, submit their files, track their application status, and receive notifications related to the process.
- **Back-end and Data Management:** Implementation of a REST API with Django, JWT authentication, CRUD modules for calls, applications, students and employees, as well as report and statistics generation for administrative decision support.
- **Deployment and Integration:** Front-end developed with Next.js/React and deployed on Vercel; back-end containerized with Docker and integrated with Google Cloud services for resource management.

**Repository:** https://github.com/JavierTarazona06/ORIUN_back

## 5. "Sharp Sight" - Technology Offers Comparison Tool
**Technologies:** Python, FastAPI, Selenium, pandas, REST API, web scraping, Vercel

Development of a price comparison backend for technology devices, integrating an automated offer collection pipeline from multiple Colombian e-commerce sites. Implementation of scraping modules, data cleaning and structuring, deterministic filtering by string matching, product categorization, REST endpoints with FastAPI, and web deployment configuration.

**Repository:** https://github.com/JavierTarazona06/SharpSight
